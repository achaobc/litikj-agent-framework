============================================================
🪐 【立体空间智能体系统】开箱必读与便携使用说明
============================================================

1. 启动方式：
   - 方式 A：双击运行「立体空间智能体系统.exe」（推荐，沉浸式原生桌面端）；
   - 方式 B：双击运行「一键启动智能体工作台.bat」（通用快捷启动器）；
   - 方式 C：通过终端执行「runtime\python.exe run.py diagnose」（微内核命令行巡检）。

2. 出厂纯净态与隐私隔离保障：
   - 本发行包已严格执行《出厂纯净态四大铁律》（docs/PACKAGING_GUIDE.md）；
   - 凭据脱敏：系统出厂不预置任何私人 API Key 或授权码；
   - 便携沙箱：所有浏览器本地存储、对话与日志全部就地隔离于 workspace/ 目录中；
   - 零系统残留：移动到 U 盘即可随身携带，删除本目录即彻底卸载，绝不污染系统注册表。

3. 模型接入引导：
   - 启动系统后，在桌面控制面板中填入您的自定义兼容 OpenAI 格式 API Key（如 DeepSeek / Qwen / Ollama 等）；
   - 也支持 100% 离线使用本地模型与规则引擎。
