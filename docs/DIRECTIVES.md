# 👑 【立体空间智能体系统】核心战略与 AI 协同规范 (Directives)

> **最高效力声明**：无论任何 AI（Antigravity、Claude、GPT 等）在接入本系统工作区时，**必须无条件严格执行本规范**。

---

## ⚡ 核心铁律：指令直达协议 (Fast-Path Protocol)

为彻底消灭“为执行简单命令而消耗海量 Token 查阅上下文”的低效浪费，本系统设立**【快慢双系统交互协议】**：

### 1. 快速直达通道 (Fast-Path Mode)
- **触发条件**：当用户输入以 `[EXEC]` 或 `!` 开头（例如：`[EXEC] run <agent_name>` 或 `[EXEC] diagnose`）；
- **AI 行为准则（铁律）**：
  1. **严禁** 调用 `view_file` 或重复探索工作区目录；
  2. **严禁** 进行任何发散性思考或长篇大论；
  3. **必须直接且仅** 调用终端工具执行 `python run.py <命令>`，并输出命令的真实运行结果；
  4. 目标：将每次常规执行的 Token 消耗压制在 **200 Token 以内，1 秒内完成响应**。

### 2. 深度参谋通道 (Slow-Path Mode)
- **触发条件**：用户采用自然语言进行开放式提问、架构探讨或业务打磨；
- **AI 行为准则**：
  1. 充当严谨客观的“商业参谋与联合操盘手”，严禁盲目附和；
  2. 深入剖析时间成本、机会成本与架构鲁棒性，把控系统质量。

---

## 🏛️ 微内核架构铁律 (Microkernel Principles)

1. **底座纯净律**：
   - `core/` 底座内核不得包含任何特定平台（如 B站、微信等）的硬编码规则或凭据；
   - 框架仅维护标准契约（`BaseAgent`, `BaseSkill`, `BaseGuard`）与任务调度引擎；
2. **规则下沉律**：
   - 任何特定业务的规则、门禁、凭据和时限检查，必须封装在各业务**智能体 (Agent)** 自身包内，不得外溢污染框架内核。
